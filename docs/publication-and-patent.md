# Publication and Patent

## Overview

This project is connected to academic research and innovation work in EV lithium-ion battery State of Health estimation using machine learning.

The work began as a B.Tech final year project titled **“Li-Ion Battery SOH Prediction using ML”** and was later extended into a research paper focused on **LightGBM-based SOH estimation**.

---

## Final Year Project

**Title:** Li-Ion Battery SOH Prediction using ML  
**Domain:** Power and Machine Learning  
**Institution:** Vishwakarma Institute of Information Technology, Pune  
**Academic Year:** 2023–2024  

The project focused on developing a machine learning-based methodology for estimating lithium-ion battery State of Health using Battery Management System data.

Key components included:

- Battery data preprocessing
- Energy and units calculation
- Charge cycle identification
- Window-based SOH calculation
- XGBoost-based SOH prediction
- Model evaluation using MSE, MAE, and R² score

---

## Published Research Paper

**Title:** EV Lithium-Ion Battery SOH Estimation based on LightGBM Model  
**Publisher:** Springer Nature  
**Conference:** ICMIB 2024  
**DOI:** https://doi.org/10.1007/978-981-97-8160-7_6  

The paper introduced a LightGBM-based methodology for predicting battery State of Health using large-scale EV battery charging data.

The research workflow included:

- Data preprocessing
- Feature selection
- Hyperparameter tuning
- Grid Search Cross Validation
- LightGBM model training
- Model evaluation
- Visualization of actual and predicted SOH

Reported LightGBM results:

| Metric | Result |
|---|---:|
| Mean Squared Error | 1.894 |
| Mean Absolute Error | 1.016 |
| R² Score | 0.9069 |
